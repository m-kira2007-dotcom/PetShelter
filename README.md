
# 🐾 PetShelter

**PetShelter** — приложение для работы с единой базой данных сети приютов для животных. Пользователь может загружать общую базу приютов, выбирать текущий формат хранения информации, просматривать интерактивную аналитику с помощью динамической фильтрации, а также управлять составом подопечных через специализированное окно результатов подборки.

---

## 📝 Основные возможности

*   **Автоматическая загрузка** или инициализация стартовой базы приютов с Рабочего стола.
*   **Поддержка двух форматов** сериализации данных на лету: **JSON** и **XML**.
*   **Мгновенный пересчет** сводной статистики сети или конкретного приюта с вычислением процентов.
*   **Интеллектуальный полиморфный фильтр** по видам животных с учетом ограничений (клаустрофобии).
*   **Просмотр выборки** подопечных в отдельном окне в виде таблицы результатов.
*   **Автоматическая выгрузка** изолированного отчета подборки при открытии таблицы.
*   **Интерактивное добавление** новых питомцев с учетом внешних правил валидации имен.
*   **Удаление выбранных животных** из коллекции (оформление выписки домой).
*   **Яркий авторский** необычный индивидуальный графический интерфейс на платформе **WPF**.

---

## 🖥️ Главное окно (MainWindow)

Главное окно отображается при запуске приложения и служит основным пультом управления фильтрами и аналитикой.

### 🔹 Элементы интерфейса
*   **Фирменный баннер** с заголовком `MORE THAN A PET / FUR FRIEND`.
*   **Выпадающий список «ВЫБЕРИТЕ ПРИЮТ»**:
    *   *Все приюты* — вывод общей сводной аналитики сети и поиск лидера по заполненности.
    *   *Конкретный приют* — «Усики да хвостики», «ADOPT ME» и др.
*   **Выпадающий список «ФОРМАТ ДОКУМЕНТОВ»** (`JSON` / `XML`) для мгновенной смены сериализатора и конвертации файлов.
*   **Выпадающий список «ВИД ЖИВОТНОГО»** (Все виды, Кот, Собака, Кролик, Попугай).
*   **Флажок «Только открытый участок»** для быстрой сортировки по типу территории вольеров.
*   **Плашка «СТАТИСТИКА БАЗЫ»**: текстовое поле вывода расчетов на базе интерфейса `ICountable`.
*   **Массивная кнопка «TAKE ME HOME (ПОИСК)»** для генерации подборки и открытия окна таблицы.

---

## 📊 Окно таблицы результатов (TableWindow)

Вспомогательное окно, предназначенное для просмотра отфильтрованных данных и редактирования содержимого приютов.

### 🔹 Возможности и элементы
*   **Интерактивная таблица (DataGrid)**:
    *   Жестко зафиксированные столбцы с русскими заголовками.
    *   Столбец **«Вид питомца»**, отображающий русские названия классов через динамическое рефлексивное свойство `TypeName`.
    *   Столбцы общих базовых характеристик: Кличка, Возраст, Вес, Рост.
    *   Графический чекбокс **«Клаустрофобия»**, наглядно доказывающий полиморфное отсечение объектов при жестких условиях содержания.
*   **Кнопка «ADOPT NEW PET»**:
    *   Добавляет новое животное в коллекцию на базе интерфейса `IChangeable`.
    *   Автоматически считывает текущий тип таблицы и создает строго подходящий вид (Собаку к собакам, Кота к котам), выбирая имя из словаря кличек.
    *   Задействует внешний делегат `Func` для валидации длины имени на лету.
*   **Кнопка «TAKE ME HOME»**:
    *   Позволяет выписать выбранного в таблице питомца из его приюта.
    *   Синхронно обновляет оперативную память и перезаписывает файлы базы на диске.

## 📁 Поддерживаемые форматы данных

*   **JSON**: Основной формат структурированного хранения базы приютов и изолированных отчетов.
*   **XML**: Альтернативный формат хранения, активируемый пользователем через графическое меню.
